# B8A1 - TypeScript & OOP Assignment

## Assignment Overview

This repository contains my B8A1 Assignment solutions covering core concepts from Modules 1, 2, and 3. The main goal of this assignment is to practice TypeScript fundamentals and Object-Oriented Programming (OOP).

## Technologies Used

- TypeScript
- JavaScript ES6
- Git & GitHub

## Problem Solving

This assignment includes 8 problems covering the following topics:

1. Optional Parameters and Nullish Coalescing Operator
2. Union Types and Type Narrowing
3. Readonly Tuples
4. Generics and Rest Parameters
5. Interfaces and Array Filtering
6. Generics with keyof
7. Classes, Inheritance, and Access Modifiers
8. Promises and Asynchronous Programming

## How to Run

Clone the repository:

```bash
git clone https://github.com/mosharof-dev/typescript-oop-assignment.git
```

Go to the project folder:

```bash
cd typescript-oop-assignment
```

Install TypeScript and tsx:

```bash
npm install -D typescript tsx
```

Run the TypeScript file:

```bash
npx tsx solutions.ts
```
